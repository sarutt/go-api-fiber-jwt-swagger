# บันทึกความต้องการระบบ (Requirements Notes)

สถานะ: กำลังรวบรวมข้อมูล (ยังไม่ออกแบบ)

## ภาพรวมธุรกิจ
- บริษัทขายเครื่องใช้ไฟฟ้ายี่ห้อ Electrolux
- ช่องทางขาย: ขายสด และ ผ่อนชำระเป็นรายเดือน
- ระบบใช้จัดการงานขายในทีม

## บทบาท (Actors)
| บทบาท | ความสามารถที่ระบุมาแล้ว |
|---|---|
| สมาชิก (ลูกค้า) | ตรวจสอบยอดที่ต้องชำระ, ชำระค่าสินค้าในแต่ละรอบบิล |
| หัวหน้า | ดูภาพรวมทั้งหมด, ดูข้อมูลการขายของแต่ละคนในทีม, จัดการคลังสินค้า |
| ลูกทีม (ฝ่ายขาย) | ดูสินค้าคงเหลือเพื่อเสนอขายลูกค้า |

## คำถามที่ยังไม่ได้คำตอบ
