# บันทึกความต้องการระบบ (Requirements Notes)

สถานะ: กำลังรวบรวมข้อมูล (ยังไม่ออกแบบ)

## ภาพรวมธุรกิจ
- บริษัทขายเครื่องใช้ไฟฟ้ายี่ห้อ Electrolux
- ช่องทางขาย: ขายสด และ ผ่อนชำระเป็นรายเดือน
- ระบบใช้จัดการงานขายในทีม

## บทบาท (Actors)
| บทบาท | ความสามารถที่ระบุมาแล้ว |
|---|---|
| สมาชิก (ลูกค้า) | ตรวจสอบยอดที่ต้องชำระ, ชำระค่าสินค้าในแต่ละรอบบิล |
| หัวหน้า | ดูภาพรวมทั้งหมด, ดูข้อมูลการขายของแต่ละคนในทีม, จัดการคลังสินค้า |
| ลูกทีม (ฝ่ายขาย) | ดูสินค้าคงเหลือเพื่อเสนอขายลูกค้า |

## การผ่อนชำระ (ตอบแล้ว)
- เงื่อนไขการผ่อนตั้งค่าได้ทั้งหมด **ต่อลูกค้าแต่ละราย** ผ่านหลังบ้าน (ไม่ใช่แพ็กเกจตายตัวทั้งบริษัท)
- ดอกเบี้ยเป็นแบบ **คงที่ (flat rate)**
- ค่าที่ตั้งได้: ยอดที่ต้องชำระ, เงินดาวน์, อัตราดอกเบี้ย และรายละเอียดอื่นๆ ทั้งหมด

## การชำระเงิน (ตอบแล้ว)
- จ่ายออนไลน์ผ่าน QR / บัตร
- โอนเงินแล้วแนบสลิป
- ผูกบัตรเครดิต ตัดอัตโนมัติทุกรอบบิล (recurring charge)

## การชำระเงิน (เพิ่มเติม)
- Payment gateway: ยังไม่มี -> ออกแบบเป็น interface กลาง เลือกเจ้าทีหลัง (ข้อสมมติ)
- ตัดบัตรไม่ผ่าน: เปลี่ยนสถานะเป็น "ค้างชำระ" + แจ้งลูกค้า + แจ้งหัวหน้า
- ตรวจสลิป: เชื่อมระบบตรวจสลิปอัตโนมัติ
- ค่าปรับจ่ายช้า: ตั้งค่าได้ว่าจะคิดหรือไม่คิด และจำนวนเงินเท่าไร
- รอบบิล: กำหนดวันครบกำหนดของเดือน ตั้งต่อลูกค้าแต่ละราย

## โครงสร้างทีม
- หัวหน้า 1 คน ดูทีมทั้งหมด
- แต่ละทีมมีลูกทีมได้หลายคน
- ลูกค้าแต่ละรายผูกกับลูกทีมที่ขายให้

## คำถามที่ยังไม่ได้คำตอบ
(ดูรายการในบทสนทนา อัปเดตไฟล์นี้เมื่อได้คำตอบ)
